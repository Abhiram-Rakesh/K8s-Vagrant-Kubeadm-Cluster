# Kubernetes Cluster using Vagrant & kubeadm

## 📌 Overview
This project provisions a multi-node Kubernetes cluster locally using
Vagrant, VirtualBox, and kubeadm.

## 🏗️ Architecture
- 1 Control Plane Node
- 2 Worker Nodes
- Ubuntu 22.04 LTS
- containerd runtime
- Calico CNI

## 🧰 Prerequisites
- Windows 10/11
- VirtualBox
- Vagrant
- Git
- Minimum 8 GB RAM (16 GB recommended)

vagrant up
